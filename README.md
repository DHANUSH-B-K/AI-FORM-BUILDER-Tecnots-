AI Form Builder & Document Autofill

AI Form Builder & Document Autofill is a web-based application that enables users to create custom forms and automatically populate them using AI-powered document extraction. By leveraging Google's Gemini 2.5 Flash model, the application can analyze PDFs and image files, extract relevant information, and intelligently map the extracted data to user-defined form fields. This eliminates manual data entry, improves accuracy, and streamlines document processing workflows.

 Features

- Dynamic form creation with customizable field types
- Support for text, textarea, number, date, dropdown, and checkbox fields
- Drag-and-drop document upload functionality
- AI-powered data extraction using Gemini 2.5 Flash
- Automatic form autofill from uploaded documents
- Manual review and editing of extracted data
- Required field validation
- JSON export and download support
- Responsive and user-friendly interface
- Secure local storage of Gemini API key

 Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Google Gemini 2.5 Flash API
- Browser Local Storage

How It Works

1. Build a custom form by adding the required fields.
2. Upload a PDF or image document containing the information.
3. Gemini AI analyzes the document and extracts relevant data.
4. Extracted values are automatically mapped to form fields.
5. Review and edit the generated data if necessary.
6. Save and export the completed form as a JSON file.
